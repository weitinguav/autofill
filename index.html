遙控無人機表單 — 手機填入

請先填寫下方資料，按儲存後，再按複製書籤網址。書籤內已含資料，在 Google 表單頁執行時不需開電腦、也不需與本頁同一網址（離開辦公室也能用）。

手機怎麼開啟本頁？（不在電腦旁時）

重點是「能開啟這個網頁」一次，以便按儲存、複製書籤。可擇一：

  • LINE／郵件：把 index.html 當附件傳給自己，在訊息裡點附件，選用 Safari 開啟或預覽後用分享開瀏覽器（依畫面為準）。
  • iCloud 雲碟／Google 雲端硬碟 App：把檔案放雲端，手機用 App 點開（若可選瀏覽器請選 Safari）。
  • 免費網頁空間（一次設定）：把 index.html 上傳到 GitHub Pages、Netlify 等，之後手機只要記住一個 https 網址即可開啟，最省事。

若在家且手邊有電腦，也可用資料夾內 開啟網頁伺服器.bat 用區網網址開本頁（選用）。

加入「自動填入」書籤（Safari 或 Chrome）

1. 先按上方儲存到此裝置，再點下方複製書籤網址（書籤內已含資料）。
2. 把書籤存進你之後要開表單的那個瀏覽器（下面擇一）。
3. 用同一個瀏覽器開台北／高雄表單（第幾頁就開第幾頁），點書籤「自動填入」。

Safari：書籤圖示 → 編輯 → 新增書籤 → 名稱「自動填入」→ 網址長按貼上 → 儲存。

Chrome（iPhone App）：右下角⋯ → 書籤 → 畫面上找新增／+或先進「行動書籤」→ 新增時名稱填「自動填入」，網址貼上（介面依版本略有不同；若找不到新增，可先隨便書籤一頁，在書籤列表裡對該書籤編輯，把網址改成貼上的內容）。填表時請用Chrome 開 Google 表單再點書籤，不要用 Safari 存的書籤去開 Chrome 分頁。

iPhone 上的 Chrome 與 Safari 一樣都是 Apple 提供的網頁核心，書籤小程式通常兩邊都能用。若瀏覽器不讓你在網址列直接貼上 javascript: 開頭的網址，屬正常，請務必用「書籤」方式執行。若提示書籤過長，請刪減選填欄後再複製。

為什麼一點書籤就回到這個 index 設定頁？
幾乎都是因為書籤存錯了：若你按「新增書籤」時人還停在這個設定頁，Safari／Chrome 會把書籤網址存成 index.html 或 file://…，點下去當然會跳回這裡。
正確做法：先按下面複製書籤網址，新增書籤時必須把「網址」欄清空，再貼上複製內容；貼上後開頭一定要是 javascript:(function(){try{var P="…（很長一串），不是 http、也不是 file。
若已存錯：到書籤 → 找到「自動填入」→ 編輯 → 把網址整段改成重新複製貼上。
